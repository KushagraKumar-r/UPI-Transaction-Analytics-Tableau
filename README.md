# UPI Transaction Analytics Dashboard | Tableau

## 📊 Project Overview

An interactive Tableau dashboard designed to analyze UPI transaction patterns and uncover insights across cities, age groups, payment methods, merchants, and transaction purposes.

## 🎯 Objectives

- Analyze transaction activity across different cities
- Understand transaction patterns across age groups
- Compare payment methods and merchants
- Analyze transaction behavior across different devices
- Enable interactive exploration using dynamic filters

## 📈 Dashboard Features

- Transaction analysis by City
- Age Group segmentation
- Payment Method analysis
- Merchant-level analysis
- Geographic visualization
- Interactive filters
- Bank-wise analysis
- Currency analysis
- Device Type analysis
- Payment Mode analysis
- Purpose-based analysis
